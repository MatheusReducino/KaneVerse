Primeiros passos

URL base: http://localhost:3000. GET / e GET /documentacao exibem esta documentação HTML (configure index.js conforme as instruções).

Os exemplos abaixo seguem os campos e as mensagens do código da API. IDs, datas e outros dados são ilustrativos; não foram capturados de uma execução do PostgreSQL. O token de login é representado por um marcador. As rotas GET podem retornar listas vazias.

Autenticação

Cadastre-se em POST /usuarios, faça login em POST /usuarios/login e use o token retornado nas rotas protegidas. O JWT dura 24 horas. As permissões e o banimento são consultados no banco.

Authorization: Bearer SEU_TOKEN
Content-Type: application/json

Rotas públicas não exigem token. Rotas Admin exigem um administrador autenticado. Autor significa o usuário que criou o registro. No Postman, escolha Authorization > Bearer Token.

Parâmetros e respostas

Substitua :id por um ID existente. IDs enviados no JSON devem ser números inteiros positivos. Listagens retornam arrays (inclusive vazios); buscas individuais retornam objetos; escritas retornam msg e, quando previsto, o registro. Senhas nunca são retornadas.

Upload

Envie PNG ou JPEG de até 2 MB usando Body > form-data no Postman, ou FormData no React. Use o campo pfp ou foto, conforme a rota. Não defina manualmente Content-Type para FormData. Os GETs de imagem retornam bytes, não JSON.

const dados = new FormData();
dados.append("pfp", foto);
const r = await fetch("http://localhost:3000/usuarios/me/pfp", {
    method: "PUT",
    headers: {Authorization: "Bearer " + token},
    body: dados
});

Regras do sistema

Posts concedem 10 pontos; comentários, 2. Reações não concedem pontos. Excluir conteúdo não desconta pontos. Títulos são desbloqueados sem gastar pontos. O cadastro não permite escolher privilégios ou pontos. Contas banidas não usam rotas protegidas.
