Documentação da API - KaneVerse

Projeto com Node.js, Express e PostgreSQL.

Endereço: http://localhost:3000

Total de rotas: 92

Como usar

Para criar conta, use POST /usuarios. Para entrar, use POST /auth/login com email e senha.

Nas rotas que precisam de login, envie Authorization: Bearer SEU_TOKEN.

Rotas de admin precisam de usuário com cargo admin. Para editar e apagar conteúdo, geralmente precisa ser dono ou admin.

Os IDs são números inteiros positivos. Para imagens, use PNG, JPG ou WEBP, até 3 MB.

Erros comuns: 400 (dados inválidos), 401 (não autenticado), 403 (sem permissão), 404 (não encontrado), 409 (duplicado).

Para criar um admin, é preciso alterar o cargo no banco. Não existe rota pública para se tornar admin.

Os Kane Points são ganhos com posts (+10), comentários (+5) e reações (+1), e gastos ao desbloquear títulos.

POST /auth/login - Pública

Confere email e senha e devolve um token JWT.

Corpo: Obrigatórios: email, senha

Exemplo de envio:

{
  "email": "kanefan@example.com",
  "senha": "SenhaForte123"
}

Resposta 200:

{
  "msg": "Login realizado",
  "token": "eyJ...exemplo",
  "usuario": {
    "id": 1,
    "nome_usuario": "KaneFan",
    "cargo": "user"
  }
}
GET /auth/me - JWT (usuario)

Consulta os dados do usuario logado.

Resposta 200:

{
  "id": 1,
  "nome_usuario": "KaneFan",
  "email": "kanefan@example.com",
  "cargo": "user",
  "banido": false
}
